# AGENTS.md

This repository's project-specific coding-agent instructions live in `CLAUDE.md`; shared PDH instructions live in `PDH-AGENTS.md`.

Before making changes:
1. Read and follow `CLAUDE.md`.
2. Read `PDH-AGENTS.md` for PDH common rules.
3. `.claude/agents/pdh-coding-engineer.md` for implementation workers
4. `.claude/agents/pdh-reviewer.md` and `pdh-reviewer-lens1.md` for review workers
5. The assigned `.claude/agents/pdh-*.md` body for QA and verification workers

Use `pdh-resume` to continue interrupted work. `[SKILLS_PATH]` resolves to `.claude/skills` for Claude Code and `.agents/skills` for Codex CLI.
